# Práctica de TypeScript

Función tipada que calcula la edad a partir de una fecha de nacimiento.

## Tecnologías

- TypeScript

## Instalación y ejecución

```bash
npm install --save-dev typescript && npx tsc app.ts && node app.js
```

## Uso

Cambia la fecha de ejemplo, compila y ejecuta el JavaScript generado.
